🎨 Portafolio de Proyectos - Interacción y Sonificación

Bienvenido al repositorio principal de mi portafolio web interactivo. Este sitio reúne una serie de encargas y proyectos desarrollados con tecnologías web (HTML5, CSS3, JavaScript ES6+, Web Audio API), integración de elementos multimedia y programación visual de audio en Max/MSP.

📦 Resumen de Entregas
📂 Entrega 1: Exploración Visual
Interfaz interactiva enfocada en el despliegue y análisis de recursos visuales y esquemas del proyecto.

📂 Entrega 2: Juego Interactivo "Birdie Colors"
Experiencia interactiva basada en HTML5 Canvas y un sistema de reproducción de audio sincronizado por colores mediante eventos del usuario.

📂 Entrega 3: Video Tutorial - Sintetizador en Max/MSP
Tutorial alojado en YouTube e incrustado en un reproductor adaptativo 16:9 con estética retro-consola.

Explora la arquitectura de un parche en Max/MSP (sintetizador.maxpat) con módulos de síntesis AM, FM y grabadora de voz con control de pitch/velocidad.

📂 Entrega 4: Sonificador de Imágenes y Datos Académicos
Sonificador de Imágenes: Convierte valores cromáticos (RGB) en tonos musicales cuantizados en una Escala Pentatónica Mayor mediante Web Audio API en tiempo real.

Sonificador de Datos: Transformación sonora de datos estadísticos sobre la distribución de académicos por sexo y nivel técnico/profesional en Chile.

🛠️ Tecnologías Utilizadas
Frontend: HTML5, CSS3 (Flexbox/Grid, gradientes, estilos retro), JavaScript ES6+.

Audio Web & Multimedia: Web Audio API (osciladores, filtros biquad, envolventes de ganancia), YouTube Embedded Player API.

Programación Sonora: Max/MSP (v9.1.5).

Hosting & Despliegue: GitHub Pages.
