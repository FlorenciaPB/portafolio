LÁMINA DE ANÁLISIS DE INTERFACES

Electrodoméstico Cotidiano: Tostadora Eléctrica

ENTRADAS (INPUTS)
Física

Palanca de Encendido

Mecanismo manual que baja el pan y activa el circuito de calentamiento.

Física / Gráfica

Perilla de Selector de Tiempo

Control giratorio graduado del 1 al 6 para ajustar el nivel de tostado.

Física

Botonera de Funciones

Botones de interrupción inmediata (Cancel), Descongelado (Defrost) y Recalentado.

SALIDAS (OUTPUTS)
Física / Térmica

Resistencias Eléctricas

Emisión de calor infrarrojo radiante para tostar la superficie del pan.

Acústica / Mecánica

Salto Automático (Pop)

Señal sonora y movimiento físico liberador al finalizar el ciclo de tiempo.

Visual / Gráfica

Indicadores LED

Luz indicadora de estado para confirmar la función activa seleccionada.
